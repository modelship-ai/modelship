# Support

- **Usage questions, config help, "how do I..."** — ask in the [Discord](https://discord.gg/apbtTdk2Am), `#help` channel.
- **Confirmed bugs and feature requests** — open a [GitHub Issue](https://github.com/modelship-ai/modelship/issues).
- **Security vulnerabilities** — see [SECURITY.md](SECURITY.md), do not open a public issue.
- **Docs** — [docs.model-ship.ai](https://docs.model-ship.ai/).
